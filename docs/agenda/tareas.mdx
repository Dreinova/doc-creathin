# Tareas

Una lista simple de pendientes.

1. Escribe la tarea en el campo de arriba (puedes darle Enter en vez de hacer clic en "Agregar").
2. Si quieres, ponle una **fecha límite**.
3. Marca la casilla cuando esté hecha — pasa al final de la lista con el texto tachado.
4. El ícono de basura la elimina.

Las tareas pendientes siempre aparecen primero, ordenadas por fecha límite.
