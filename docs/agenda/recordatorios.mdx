# Recordatorios

Como las Tareas, pero siempre con **fecha** y un espacio para una **nota** — pensado para cosas puntuales como "llamar al proveedor de cera el martes".

- Los recordatorios **vencidos** (su fecha ya pasó y no están marcados como hechos) se resaltan con una etiqueta de aviso.
- Márcalos como hechos con la casilla, o elimínalos con el ícono de basura.
- Se ordenan por fecha, los pendientes primero.
