# Posventa

Para no olvidar hacerle seguimiento a un cliente después de entregarle su pedido: ¿llegó bien?, ¿quedó satisfecho?

## Ventas entregadas sin seguimiento

En cuanto marcas una venta como **Entregada** en [Ventas](../comercio/ventas), aparece aquí arriba en un aviso. Haz clic en **"Crear seguimiento"** para agregarla a tu lista con un clic.

## Seguimiento manual

También puedes agregar un seguimiento suelto (sin ligarlo a una venta): escribe el nombre del cliente y, si quieres, una nota.

Marca la casilla cuando ya hiciste el seguimiento, o elimínalo con el ícono de basura.
