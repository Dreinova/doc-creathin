# Proveedores

A quién le compras tus insumos. Se abre desde **"Mi empresa"**, al final del menú lateral, o con el enlace **"Proveedores"** arriba del [Catálogo de insumos](./catalogo-de-insumos).

## Agregar o editar un proveedor

**"Nuevo proveedor"** agrega una fila vacía. Completa **nombre**, **ciudad**, **dirección**, **contacto** (teléfono o WhatsApp) y, si tiene, el enlace a su **catálogo**. Todo se guarda solo mientras escribes.

## Dónde se usan

Una vez que tienes proveedores cargados, puedes elegirlos (en vez de escribir el nombre a mano) en dos lugares:

- En cada insumo del [Catálogo de insumos](./catalogo-de-insumos), como su proveedor habitual.
- Al registrar una [Compra](./finanzas/compras).

## Buscar y paginar

Usa el buscador (por nombre o ciudad) para encontrar uno rápido. La lista se divide en páginas de 15.

## Eliminar un proveedor

El ícono de basura lo elimina. Los insumos y compras que lo tenían asignado quedan **sin proveedor** — no se borran ni se modifican.
