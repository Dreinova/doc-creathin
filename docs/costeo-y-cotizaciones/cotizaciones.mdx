# Cotizaciones

El paso 5 del [Costeo](./costeo) arma la cotización que le envías a tu cliente; la sección **Cotizaciones** del menú es donde ves y administras todas las que ya guardaste.

## Armar la cotización

1. **Cliente**: escribe el nombre — si ya cotizaste antes para ese cliente, aparece en una lista para autocompletar sus datos (teléfono, correo, dirección).
2. **Datos de la cotización**: número, fecha, estado y vigencia (en días).
3. **Productos y servicios**: tus velas del costeo aparecen solas, con su precio ya calculado. Puedes ajustar cantidad y descuento por cada una, o agregar un **producto adicional** (algo fuera del costeo, como empaque especial o envío) con su propio precio.
4. **Condiciones y notas**: texto que verá tu cliente en el documento.
5. **Notas internas**: solo las ves tú — nunca se imprimen ni se le muestran al cliente.
6. **Tu negocio y estilo del documento**: nombre, NIT, contacto, logo y color del documento (se guarda para todas tus próximas cotizaciones).

Usa el interruptor **"Mostrar costo y margen"** para ver u ocultar esa columna mientras editas — es solo para ti, el cliente nunca la ve.

## Guardar y compartir

- **Guardar cotización**: queda registrada en tu historial. Mientras no la guardes, no aparece en la lista de Cotizaciones.
- **Vista del cliente**: muestra el documento limpio, sin costos ni notas internas — así es como lo verá tu cliente.
- **PDF**: desde la vista del cliente, descarga o imprime el documento.
- Si haces cambios después de guardar, verás **"Cambios sin guardar"** — usa **"Guardar cambios"** para actualizarla.

## Estados

| Estado | Significado |
|---|---|
| Borrador | Aún la estás armando, no se ha enviado. |
| Enviada | Ya la compartiste con el cliente. |
| Aprobada | El cliente la aceptó. |
| Rechazada | El cliente no la aceptó. |
| Vencida | *(automático)* Pasó la vigencia sin que la marcaras como aprobada o rechazada. |

Cambia el estado desde el menú **⋯** de cada cotización, o con el botón rápido **"Aprobar"** que aparece sobre las enviadas.

## Convertir en venta

Cuando una cotización está **Aprobada**, el menú **⋯** te deja **"Convertir en venta"** — esto la pasa a [Ventas](../comercio/ventas) con un número de venta propio, sin alterar la cotización original.

## Otras acciones

- **Duplicar como borrador**: crea una copia editable para una cotización nueva (útil para un cliente similar o una repetición).
- **Eliminar**: borra la cotización del historial. Si ya tiene una venta registrada, elimina primero la venta.

Desde la lista de Cotizaciones puedes filtrar por estado y buscar por cliente o número.
