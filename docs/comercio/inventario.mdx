# Inventario

Muestra cuánto tienes disponible de cada **insumo** y cada **producto terminado**, en dos listas lado a lado.

## Cómo se actualiza

El inventario **se mueve solo**:

- Cuando registras una **[Compra](../finanzas/compras)**, sube el stock del insumo comprado.
- Cuando registras una **[Producción](./produccion)**, sube el stock del producto fabricado.
- Si eliminas una compra o una producción, el movimiento se revierte automáticamente.

## Ajustar manualmente

Puedes escribir directamente sobre el número de existencias de cualquier insumo o producto — útil para corregir un conteo físico o cargar tu inventario inicial la primera vez. Este ajuste no queda registrado como compra ni como producción, solo cambia el número.

Los enlaces **"Editar catálogo"** y **"Editar productos"** te llevan directo al [Catálogo de insumos](../catalogo-de-insumos) o a [Productos](./productos) si necesitas agregar algo nuevo primero.
