# Producción

Registra cada lote de velas que fabricas.

1. Elige el **producto** (debe existir primero en [Productos](./productos)).
2. Indica la **cantidad fabricada**, la **fecha** y, si quieres, una **nota**.
3. Haz clic en **"Registrar"**.

Esto aumenta automáticamente el stock de ese producto en [Inventario](./inventario). Si eliminas el registro, el stock se revierte.

:::note
Este registro no descuenta insumos automáticamente. Si quieres reflejar el consumo de materia prima de ese lote, ajusta el inventario de insumos a mano, o anótalo como referencia en el campo de notas.
:::
