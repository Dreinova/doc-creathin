# Moldes y envases

Ficha de referencia por molde o envase: cuánto pesa vacío, cuánto pesa lleno de agua, y de ahí cuánta cera, fragancia y aditivo necesita para llenarlo. Útil cuando vas a armar la receta de un producto nuevo y no quieres recalcular todo desde cero. Se abre desde **"Mi empresa"**, al final del menú lateral, o con el enlace **"Moldes y envases"** arriba del [Catálogo de insumos](./catalogo-de-insumos).

:::note
No reemplaza al [Catálogo de insumos](./catalogo-de-insumos): un envase que además **compras** (por ejemplo un recipiente de policarbonato) debe existir en ambos lados — aquí guardas sus datos físicos y de receta, allá su precio y stock. Puedes enlazarlos con el campo **"Insumo enlazado"**.
:::

## Campos

| Campo | Qué significa |
|---|---|
| Nombre | Nombre del molde o envase. |
| Insumo enlazado | El insumo del catálogo que corresponde a este envase (vacío si es un molde reutilizable que no se compra). |
| Vacío / Con agua | Peso del envase vacío y lleno de agua — de ahí se calcula por desplazamiento cuánto cabe. |
| Vela | Peso de vela que cabe en el molde/envase. |
| Cera / Fragancia / Aditivo | Cantidades estándar para llenarlo. |
| Alto / Ancho | Dimensiones, en cm. |

## Buscar, filtrar y paginar

Usa el buscador (por nombre) o el filtro **"Con insumo enlazado / Moldes reutilizables"** para encontrar uno rápido. La lista se divide en páginas de 15.

## Agregar, editar o eliminar

**"Nuevo"** agrega una fila vacía — complétala con los pesos y cantidades que midas. Todo se guarda solo mientras escribes. El ícono de basura elimina la fila.
