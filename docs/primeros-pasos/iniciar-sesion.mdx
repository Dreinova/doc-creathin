# Iniciar sesión

1. Entra a **[creathin.vercel.app](https://creathin.vercel.app)**.
2. Escribe la contraseña que te compartieron y presiona **Entrar**.
3. Quedas adentro por 30 días en ese navegador — no necesitas volver a escribirla cada vez.

Para salir, usa **"Mi empresa" → "Salir"** en la parte de abajo del menú lateral.

:::note
Toda la app usa una sola contraseña compartida (no hay usuarios individuales). Si necesitas cambiarla, pídele a quien administra el sistema que la actualice.
:::
